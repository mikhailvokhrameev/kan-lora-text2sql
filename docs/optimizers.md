# Оптимизатор

Для всех обучаемых методов используется `torch.optim.AdamW`. Фабрика
`build_optimizer(model, config)` получает все параметры с `requires_grad=True`
ровно по одному и возвращает сам оптимизатор. `learning_rate`, `weight_decay`
и `max_grad_norm` задаются в YAML; имя оптимизатора в конфигурации не требуется.
Замороженные параметры основы в оптимизатор не входят. Обрезание нормы градиента
по всем обучаемым параметрам и очистка через `zero_grad(set_to_none=True)`
выполняются в цикле обучения.

Удаление Muon сокращает матрицу исследования и является методическим решением:
сравниваются только прогоны AdamW при одинаковых данных, зерне, настройках,
точности и протоколе оценки. Старые прогоны Muon нельзя усреднять с новыми.
Проверки `tests/train/test_optimizers.py` покрывают параметры всех трёх методов,
отсутствие дублей, шаг и очистку градиентов.
