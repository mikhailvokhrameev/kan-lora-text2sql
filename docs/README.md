# Документация проекта

- [Адаптеры](adapters.md): LoRA, DoRA и KAN-LoRA, формулы и масштаб входа.
- [Оптимизатор](optimizers.md): AdamW и состав обучаемых параметров.
- [Цикл обучения](train-loop.md): накопление, обрезание, валидация и отчёт.
- [Запуск эксперимента](experiment-runner.md): конфигурация и карточка результата.
- [Таблицы](make-tables.md): агрегация и проверка сопоставимости.
- [Проверка окружения](environment-check.md): CUDA, данные и зависимости.
- [Данные](data.md), [подготовка батчей](collate.md), [генерация](generate.md), [Exact Match](exact_match.md)
  и [Execution Accuracy](execution.md).

Результаты сравнимы только при одинаковых данных, зерне, гиперпараметрах,
точности и протоколе оценки. Переход на сокращённую матрицу AdamW исключает
сравнение со старыми прогонами Muon; затронутые ячейки необходимо пересчитать.
