# Техническая документация

Документация описывает фактически реализованное поведение кода в `src/`,
`scripts/` и покрывающие их тесты в `tests/`. Спекулятивные или ещё не
написанные компоненты здесь не описываются — план работ по ним находится в
`docs/superpowers/plans/2026-09-09-kan-lora-text2sql.md`.

Документы обновляются в рамках той же задачи, в которой меняется описываемое
поведение.

## Состав

- [`environment-check.md`](environment-check.md) — диагностика окружения
  (`scripts/check_environment.py`): поддержка видеокарты, наличие `Muon`,
  проверка файлов наборов данных Spider и PAUQ.
- [`adapters.md`](adapters.md) — B-сплайновый базис, слой Колмогорова —
  Арнольда, общий интерфейс адаптера `AdapterLinear`, реализации LoRA, DoRA
  и KAN-LoRA, и единый внедритель адаптеров в модель (`inject.py`).
- [`data.md`](data.md) — сериализация схемы БД и загрузчики Spider/PAUQ:
  чтение примеров, раскладка файлов наборов, воспроизводимое урезание
  обучающей выборки.
- [`collate.md`](collate.md) — промпт, токенизация и маска функции потерь
  по SQL (`data/collate.py`): рамка промпта, усечение по голове промпта,
  сборка батча с динамическим паддингом.
- [`optimizers.md`](optimizers.md) — AdamW и Muon за единым интерфейсом
  (`train/optimizers.py`): разводка обучаемых параметров по размерности,
  покрытие Muon для LoRA/DoRA/KAN-LoRA, обрезание градиента.
- [`train-loop.md`](train-loop.md) — цикл обучения и замер пиковой
  видеопамяти (`train/loop.py`, `train/memory.py`): накопление градиента,
  чекпоинтинг, логирование доли активаций в сетке для KAN-LoRA, санитарный
  тест на переобучение двадцати примеров и почему он размораживает больше,
  чем только адаптеры, на игрушечной тестовой модели.
- [`generate.md`](generate.md) — пакетная жадная генерация SQL
  (`eval/generate.py`): почему отбор всегда жадный, дополнение слева,
  обрезание продолжения по первому переводу строки или `;`, и фикстура
  `TinyTokenizer` для тестов генерации без сети.

## Срез состояния

Документация актуальна по состоянию на коммит с генерацией SQL
(`feat: add batched greedy SQL generation`). Из адаптеров реализованы и
подключены к модели общий интерфейс, LoRA, DoRA, KAN-LoRA и единый
внедритель; из данных — сериализация схемы БД, чтение примеров с
воспроизводимым урезанием выборки и сборка промпта/токенов/маски функции
потерь для обучения; из обучения — разводка обучаемых параметров между
AdamW и Muon, а также сам цикл обучения с накоплением градиента,
чекпоинтингом и замером пиковой видеопамяти; из оценки — пакетная жадная
генерация SQL. Ещё не реализованы: официальная метрика Exact Match,
Execution Accuracy, мера выученной нелинейности, сборка конфигурации и
карточки результата прогона, замер задержки генерации со слиянием адаптера
и без — см. `docs/superpowers/plans/2026-09-09-kan-lora-text2sql.md`.
