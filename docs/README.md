# Техническая документация

Документация описывает фактически реализованное поведение кода в `src/`,
`scripts/` и покрывающие их тесты в `tests/`. Спекулятивные или ещё не
написанные компоненты здесь не описываются — план работ по ним находится в
`docs/superpowers/plans/2026-09-09-kan-lora-text2sql.md`.

Документы обновляются в рамках той же задачи, в которой меняется описываемое
поведение.

## Состав

- [`environment-check.md`](environment-check.md) — диагностика окружения
  (`scripts/check_environment.py`): поддержка видеокарты, наличие `Muon`,
  проверка файлов наборов данных Spider и PAUQ.
- [`adapters.md`](adapters.md) — B-сплайновый базис, слой Колмогорова —
  Арнольда, общий интерфейс адаптера `AdapterLinear` и реализация LoRA.

## Срез состояния

Документация актуальна по состоянию на коммит с реализацией LoRA-адаптера
(`feat: add LoRA adapter`). Из адаптеров реализованы только общий интерфейс и
LoRA; DoRA и нелинейный KAN-LoRA-адаптер, объединяющий низкоранговую
проекцию со слоем Колмогорова — Арнольда, ещё не написаны — сам слой
(`KANLayer`) уже существует и протестирован как самостоятельный строительный
блок, но пока не подключён ни к одному адаптеру.
