# Сборка таблиц

`python scripts/make_tables.py --results results --output results` читает
карточки JSON и создаёт `results/tables.md` с основной матрицей. Для каждой
пары метода и набора данных приводятся средние Exact Match и Execution
Accuracy с половиной размаха по зёрнам, пик видеопамяти и число обучаемых
параметров. Отсутствующая Execution Accuracy не усредняется с нулём.
Базовая модель без адаптера выводится отдельно; если карточек нет, строка
указывает, что прогон отсутствует.

Перед усреднением сравниваются сохранённые конфигурации: кроме зерна они должны
совпадать; у базовой модели настройки адаптера и оптимизатора не применяются.
Различающиеся настройки вызывают ошибку с именами полей и карточек. Не смешивайте
результаты старой матрицы Muon или иной формулировки с текущими результатами.
Окончательная форма таблицы определяется следующим этапом 18E.
