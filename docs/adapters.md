# Адаптеры

`AdapterConfig` задаёт ранг `rank`, множитель `alpha`, параметры сплайновой
сетки и `learn_input_scale`. Внедритель заменяет выбранные линейные проекции
замороженной модели на адаптеры; параметры исходной основы не обучаются.
Коэффициент масштабирования поправки равен `alpha / rank`. Матрица B начинает
с нулей, поэтому начальный выход каждого метода совпадает с выходом основы.

LoRA вычисляет поправку `(alpha / rank) B A x`. DoRA раскладывает вес по
выходным каналам на модуль и направление: направление равно `W + (alpha / rank)
BA`, делится на норму строки с `detach`, после чего умножается на обучаемый
модуль. При инициализации модуль равен норме исходной строки веса.

KAN-LoRA вычисляет `(alpha / rank) B φ(Ax)`, где φ — `KANLayer` с обучаемыми
одномерными функциями на рёбрах. Каждое ребро складывает взвешенную SiLU и
B-сплайн; выход канала — сумма рёбер. Для входного канала используется
масштаб `s = input_scale`:

```text
out_j = Σ_i s_i · φ_ji(x_i / s_i)
```

Масштаб растягивает конечную сетку и участвует в формулировке метода. Для
деления `input_scale_divisor()` ограничивает модуль снизу значением `1e-4`,
сохраняя знак; обратное умножение использует исходный параметр. Изначально
масштаб равен единице, базовые веса обнулены, коэффициенты диагональных
сплайнов заданы абсциссами Гревилля, а остальные равны нулю: внутри сетки
слой тождественен. За пределами сетки сплайновый базис обнуляется. Настройка
`learn_input_scale` сохраняется в конфигурации и по умолчанию включает обучение
масштаба; отдельный CLI-флаг абляции удалён.

Число параметров проверяется аналитическими формулами и фактическим подсчётом.
Эталоны `tests/adapters/test_cleanup.py` фиксируют выходы и градиенты всех
трёх адаптеров при ненулевой B, а также tiny-генерацию и EM/EA. Удаление
пассивной диагностики, слияния и разводки параметров оптимизаторов не меняет
формулы, инициализацию, сетку или обучаемые параметры. Это решение сокращает
исследовательскую матрицу; данные прежних и новых конфигураций смешивать нельзя.


### Сохранение и восстановление

`adapter.pt` содержит словарь конфигурации и только именованные обучаемые
CPU-тензоры, включая magnitude DoRA и input_scale KAN-LoRA. Замороженные веса,
буферы сетки и состояние оптимизатора не сохраняются: буферы создаются
конструктором. Для восстановления загрузите свежую базу с закреплёнными
`model_name` и `model_revision`, затем вызовите `restore_adapter(model, path)`.
Функция проверяет имя и ревизию базы, внедряет адаптер и проверяет имена и
формы тензоров; при несовместимости возникает `ValueError`, а исходные слои и
флаги обучаемости восстанавливаются. Возобновление
обучения из checkpoint не предусмотрено.
