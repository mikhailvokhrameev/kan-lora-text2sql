# Проверка окружения

`python scripts/check_environment.py --data-root data` проверяет версию PyTorch,
доступность CUDA, архитектуру видеокарты в сборке, наличие данных NLTK
`punkt_tab` и необходимых файлов Spider и PAUQ. Отсутствующий файл или
несовместимость сообщаются в отчёте, а проверка завершается ненулевым кодом.
Установка зависимостей: `uv sync --extra dev`, затем
`uv run python -m nltk.downloader punkt_tab`.

На целевой GTX 1080 Ti (Pascal, sm_61) обучение выполняется в fp32: bf16,
FlashAttention-2 и 4-bit bitsandbytes не используются. Наличие поддержки sm_61
в установленной сборке PyTorch следует проверить на целевой машине. CPU на Mac
подходит для разработки и крошечных тестовых фикстур; ноль пика памяти на CPU
означает, что она не измерялась. Проверка окружения не запускает обучение.

Проверка читает JSON и русские поля PAUQ, исполняет все эталоны полного dev
на соответствующих SQLite и сообщает ошибки. CUDA проверяется реальным fp32
forward/backward и синхронизацией в дополнение к версии, устройству и списку
архитектур. Отсутствие CUDA на Mac не подтверждает поддержку GPU.

Инвентаризация API: используются `torch.load(weights_only=True)`, AdamW,
DataLoader, автоградиент, генераторы, CUDA memory stats и стандартные тензорные
операции. Muon не используется. Нижняя версия torch 2.6.0 проверена
полным pytest в отдельном CPU-окружении Python 3.12.4 с transformers 4.57.6:
279 passed, 3 skipped. Основное окружение: torch 2.14.0 и transformers 5.17.0,
281 passed, 1 skipped. Эти CPU-тесты не подтверждают работоспособность
CUDA-сборки на Pascal.

CPU smoke новой реализации не выполнялся по запрету пользователя на запуски
обучения; восемь карточек v2 и результаты шага 9 не проверены и не создавались.
Проверка на целевой GTX 1080 Ti и полный dev остаются отдельной работой.
